Setup

Run a command through Keystub

keystub run -- npm run dev
keystub run --env my-app/prod -- node server.js

This gives the command its own proxy token in that environment (named after the git worktree), points it at the proxy, and sets each service's key variable to that token. Without --env it uses $KEYSTUB_ENV, else default/dev.

{{if .Data.QuickStart}}

Quick start, without the proxy

SDKs with a base-URL setting can call Keystub directly: no proxy, no CA. Set these, and set the service's key variable to a proxy token from the Tokens page, or let keystub env --direct print them all.

Use it in every shell in a repo

Add this to the repo's .envrc (direnv). Each worktree gets its own key.

eval "$(keystub env)"
